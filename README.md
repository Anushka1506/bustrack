\# BusTrack – College Bus Seat \& Route Management System



BusTrack is a simple web-based application developed using Flask to manage college bus routes, timings, seat availability, and student bookings.



\## Problem Statement



Managing college bus routes, timings, seat availability, and student bookings manually can be difficult and time-consuming. Students may not have a simple way to check available buses and seats before travelling.



BusTrack provides a simple platform where students can view available buses and book or cancel a seat.



\## Features



\- View available college buses

\- View routes and timings

\- View available seats

\- Book a bus seat

\- Enter and validate phone number

\- View current bookings

\- Cancel a booking

\- JSON API for bus data

\- Health check endpoint

\- Running Git commit displayed on the website
